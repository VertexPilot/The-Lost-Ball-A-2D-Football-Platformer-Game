# 🎮 The Lost Ball

### A 2D Football Platformer Game

**The Lost Ball** is a 2D platformer game developed using Unity 6 and C#. Players take control of a football and navigate through challenging levels, avoid dangerous obstacles, collect football stars, and reach the finish gate.

The game combines platforming mechanics, collectible-based scoring, and entertaining moments to create an engaging gameplay experience.

## 🎯 Game Overview

- **Game Title:** The Lost Ball
- **Genre:** 2D Platformer
- **Game Engine:** Unity 6
- **Programming Language:** C#
- **Platform:** Web Browser (WebGL)
- **Project Type:** Personal Game Development Project

## ✨ Key Features

- **Player Movement:** Control the football through different environments.
- **Jump Mechanics:** Jump over obstacles and navigate challenging areas.
- **Collectibles:** Collect football stars to increase your score.
- **Obstacles:** Avoid dangerous obstacles throughout each level.
- **Jump Pads:** Use jump pads to reach difficult areas.
- **Scoring System:** Earn points through collected stars, time bonuses, and level bonuses.
- **Level Progression:** Complete levels and continue to the next challenge.
- **Meme Videos:** Enjoy random meme videos during victory and game-over moments.
- **Restart System:** Restart a level when needed.

## 🕹️ Gameplay

The main objective is to guide the football safely through each level.

Players must:
1. Navigate through the level.
2. Avoid obstacles and dangerous areas.
3. Collect football stars.
4. Use jump pads to overcome challenging sections.
5. Reach the finish gate to complete the level.
